# FBDNN (Compiled Python Module)

This repository contains a compiled Python extension module (`.pyd`) for the FBDNN neural network implementation.

## 🔒 Source Code Hidden

The source code is intentionally excluded to protect proprietary logic. Only the compiled `.pyd` file is distributed.  
This module is built using [Cython](https://cython.org/), and cannot be read or reverse-engineered easily.

## 📦 Included Files

- `FBDNN.pyd`: Compiled extension module
- `setup.py`: (Optional) Setup script for local compilation (source code not included)
- `.gitignore`, `LICENSE`, and this `README.md`

## 🧠 Module Overview

This module contains a custom neural network model named **FBDNN** designed for growing neural network.

## 🛠 Requirements

- **Windows 64-bit**
- **Python 3.9** (must match the version used to compile the `.pyd`)
- Compatible only with the system used to build the module (Windows x64)

## 📥 Installation

Clone the repository and make sure the `.pyd` file is in the same folder as your script:
